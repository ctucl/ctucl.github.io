# ctucl.github.io

Personal website of Chintan A. Trivedi, PhD. Served by GitHub Pages at https://ctucl.github.io

## Adding photos

Put these files in `images/`. Each one appears on the page as soon as it is pushed; until then its card shows text only.

| File | Shows |
| --- | --- |
| `portrait.jpg` | You, or you at a rig (hero, portrait 4:5) |
| `vast.jpg` | VAST BioImager |
| `spatial.jpg` | Microfluidic chamber or Airyscan image |
| `pybridizer.png` | Probe alignment plot |
| `vr.jpg` | Virtual reality setup |
| `tracking.jpg` | High-speed behaviour rig |

Landscape photos at about 4:3 fit the cards best.
