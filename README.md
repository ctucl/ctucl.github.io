# ctucl.github.io

Personal website of Chintan A. Trivedi, PhD. Served by GitHub Pages at https://ctucl.github.io

## Adding photos

Put these files in `images/`. Each one appears on the page as soon as it is pushed; until then its slot shows a "coming soon" placeholder.

| File | Shows |
| --- | --- |
| `portrait.jpg` | You, or you at a rig (hero, portrait 4:5) |
| `vast.jpg` | VAST BioImager |
| `spatial.jpg` | Segmented cells and transcripts (no gene names) |
| `pybridizer.png` | Probe alignment plot (from the pybridizer repo) |
| `tracking.jpg` | High-speed behaviour rig |

Landscape photos at about 4:3 fit the cards best.

## Movies and 3D models

| File | Shows |
| --- | --- |
| `media/spatial.webm` + `media/spatial.mp4` | Looping movie of segmented cells and transcripts (shown over `images/spatial.jpg`, which is used if the movie is missing) |
| `models/spatial-chamber.glb` | Interactive 3D model of the microfluidic staining chamber |
| `models/behaviour-chamber.glb` | Interactive 3D model of the behaviour chamber |

Movies autoplay muted and loop; visitors with reduced motion turned on see them paused. 3D models load when scrolled into view and can be dragged to rotate. FreeCAD STL exports need converting to `.glb` first.
